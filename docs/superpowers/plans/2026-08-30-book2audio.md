# book2audio: план разработки

> **Для агентов:** ОБЯЗАТЕЛЬНЫЙ САБ-СКИЛЛ: `superpowers:subagent-driven-development` (рекомендуется) или `superpowers:executing-plans`. Шаги помечены чекбоксами `- [ ]`.

**Цель.** Локальное веб-приложение: PDF, EPUB и FB2 превращаются в аудиокнигу m4b с главами. Русский и английский. Слушать на iPhone во время тренировок, часто на x2.

**Архитектура.** Конвейер из 8 стадий. Ядро это библиотека плюс CLI, веб сверху тонкий. Два протокола (`Extractor`, `TTSEngine`) держат всю систему: сверху течёт текст, снизу потребляется wav. Синтез локальный, нативно на Mac.

**Стек.** Python 3.12, uv, FastAPI, typer, PyMuPDF, ebooklib, lxml, pysbd, num2words, torch (Silero v5), mlx-audio (Kokoro-82M), ffmpeg.

---

## Контекст

Репозиторий пустой: README, LICENSE и черновик `Development Plan.md`.

Черновик был написан под Docker и движки Silero v4 + Piper. Разбор нашёл два слабых места.

**Docker на macOS не даёт GPU.** Плюс запись тысяч мелких wav через VirtioFS медленная. Изоляция здесь не окупается: проект внутренний, пользователь один.

**Silero v4 не ставит ударения.** Русский TTS без ударений выматывает на длинной дистанции, а книга это 12 часов. Piper для английского звучит механически. Голос это главное требование, и черновик его не закрывал.

## Что поменялось против черновика

| Было | Стало | Почему |
|---|---|---|
| Docker, 2 контейнера | Нативно на Mac, `uv` + venv | Быстрее, доступ к MPS, меньше слоёв |
| Silero v4 | Silero v5 (`v5_5_ru`) | Автоударения, омографы, вопросительная интонация |
| Piper (en) | Kokoro-82M через mlx-audio | Живее, Apache-2.0, быстро на Apple Silicon |
| PDF + EPUB | PDF + EPUB + FB2 | FB2 это XML, парсер самый простой из трёх |
| Веб + воркер + поллинг SQLite | Один процесс, фоновый поток | Пользователь один, задача одна |
| 9 эвристик чистки на всё | Тяжёлая чистка только для PDF | В EPUB и FB2 разметка уже есть |
| Полный автомат | Экран предпросмотра текста | Увидеть мусор до того, как потратил полчаса на синтез |
| Ссылка на скачивание | Копия в iCloud Drive | Файл сам приезжает в Файлы на iPhone |

## Глобальные ограничения

Действуют на все задачи всех фаз.

- Python 3.12, зависимости через `uv`, никакого pip напрямую
- macOS Apple Silicon, запуск нативный. Docker не используется
- Системное через brew: `ffmpeg`, `espeak-ng`
- Линтер и форматтер: `ruff`. Гоняется перед каждым коммитом
- Тесты, которым нужна сеть или веса моделей, помечены `@pytest.mark.slow` и в обычный прогон не входят
- Языки только `ru` и `en`. Литерал: `Literal["ru", "en"]`
- Один процесс, один пользователь, только localhost. Авторизации нет
- Синтез всегда на скорости x1. Ускорение делает плеер на телефоне
- Промежуточное аудио: wav, 24000 Гц, 16 бит, моно
- Финал: m4b, AAC 64 кбит/с, моно
- Все пути в коде через `pathlib.Path`, строки не склеиваем

## Как работаем

Дисциплина не для галочки. Проект на 6 дней, и без неё чистка текста расползётся.

- **Изоляция.** Перед фазой 1 создаём worktree через `superpowers:using-git-worktrees`
- **TDD.** Каждая задача идёт по циклу `superpowers:test-driven-development`: падающий тест, минимальная реализация, зелёный тест, коммит. Реализация вперёд теста не пишется
- **Чистый код.** `elman-practices:elman-clean-code` для читаемости, `elman-practices:elman-testing-tdd` для выбора уровня теста
- **Проверка до заявления.** `superpowers:verification-before-completion`. Задача закрыта только после того, как команда прогнана и вывод показан
- **Ревью.** В конце каждой фазы `superpowers:requesting-code-review`. Ответ на замечания через `superpowers:receiving-code-review`
- **План на фазу.** Детальный TDD-план пишется отдельно перед каждой фазой через `superpowers:writing-plans` и кладётся в `docs/superpowers/plans/`

Почему план не расписан на все 48 часов сразу: результат фазы 0 меняет фазы 1-5. Выбранный голос диктует частоту дискретизации, лимит длины чанка и правила нормализации текста. Расписывать это до прослушивания значит переписывать потом.

# book2audio/audio.py
"""Запись и преобразование wav. Всё моно, 16 бит."""

import subprocess
import wave
from pathlib import Path

import numpy as np

SAMPLE_WIDTH = 2


def write_wav_mono16(path: Path, samples: np.ndarray, sample_rate: int) -> None:
    """Пишет float-семплы из диапазона [-1, 1] в wav. Выход за диапазон обрезается."""
    clipped = np.clip(samples, -1.0, 1.0)
    pcm = (clipped * 32767).astype("<i2")
    with wave.open(str(path), "wb") as w:
        w.setnchannels(1)
        w.setsampwidth(SAMPLE_WIDTH)
        w.setframerate(sample_rate)
        w.writeframes(pcm.tobytes())


def silence(path: Path, seconds: float, sample_rate: int) -> None:
    """Пишет wav с тишиной заданной длины."""
    frames = int(round(seconds * sample_rate))
    write_wav_mono16(path, np.zeros(frames, dtype=np.float32), sample_rate)


def change_speed(src: Path, dst: Path, factor: float) -> None:
    """Меняет темп без изменения высоты тона. atempo держит диапазон 0.5-100."""
    subprocess.run(
        ["ffmpeg", "-y", "-i", str(src), "-filter:a", f"atempo={factor}", str(dst)],
        check=True,
        capture_output=True,
    )
```

# book2audio/tts/silero.py
"""Русский синтез через Silero v5.

Модель v5_5_ru сама расставляет ударения и разбирает омографы,
поэтому стадия чистки этим не занимается.
"""

from pathlib import Path

import torch

from book2audio.audio import write_wav_mono16

VOICES: dict[str, list[str]] = {
    "v5_5_ru": ["aidar", "baya", "kseniya", "xenia", "eugene"],
    "v5_ru": ["aidar", "baya", "kseniya", "xenia", "eugene"],
    "v5_cis_base": ["ru_aidar", "ru_baya", "ru_kseniya", "ru_xenia", "ru_eugene"],
}

ALLOWED_SAMPLE_RATES = (8000, 24000, 48000)


class SileroEngine:
    name = "silero"

    def __init__(self, sample_rate: int = 24000, model_id: str = "v5_5_ru") -> None:
        if model_id not in VOICES:
            raise ValueError(f"неизвестная модель: {model_id}")
        if sample_rate not in ALLOWED_SAMPLE_RATES:
            raise ValueError(f"Silero не умеет частоту {sample_rate}")
        self.sample_rate = sample_rate
        self.model_id = model_id
        self._model = None

    def voices(self) -> list[str]:
        return list(VOICES[self.model_id])

    def _load(self):
        if self._model is None:
            model, _ = torch.hub.load(
                repo_or_dir="snakers4/silero-models",
                model="silero_tts",
                language="ru",
                speaker=self.model_id,
            )
            model.to(torch.device("cpu"))
            self._model = model
        return self._model

    def synth(self, text: str, voice: str, out_path: Path) -> None:
        if voice not in self.voices():
            raise ValueError(f"неизвестный голос: {voice}")
        if not text.strip():
            raise ValueError("пустой текст")
        audio = self._load().apply_tts(text=text, speaker=voice, sample_rate=self.sample_rate)
        write_wav_mono16(out_path, audio.numpy(), self.sample_rate)
```

# book2audio/tts/kokoro.py
"""Английский синтез через Kokoro-82M на MLX.

Работает на Apple GPU. Языковой код берётся из префикса голоса:
a это американский английский, b это британский.
"""

from pathlib import Path

import numpy as np

from book2audio.audio import write_wav_mono16

VOICES: list[str] = [
    "af_heart",
    "af_bella",
    "af_nova",
    "af_sky",
    "am_adam",
    "am_echo",
    "am_michael",
    "bf_alice",
    "bf_emma",
    "bm_daniel",
    "bm_george",
]

LANG_BY_PREFIX = {"a": "a", "b": "b"}


class KokoroEngine:
    name = "kokoro"
    sample_rate = 24000

    def __init__(self, model_repo: str = "mlx-community/Kokoro-82M-bf16") -> None:
        self.model_repo = model_repo
        self._model = None

    def voices(self) -> list[str]:
        return list(VOICES)

    def _lang_code(self, voice: str) -> str:
        prefix = voice[0]
        if prefix not in LANG_BY_PREFIX:
            raise ValueError(f"не понял язык голоса: {voice}")
        return LANG_BY_PREFIX[prefix]

    def _load(self):
        if self._model is None:
            from mlx_audio.tts.utils import load_model

            self._model = load_model(self.model_repo)
        return self._model

    def synth(self, text: str, voice: str, out_path: Path) -> None:
        if voice not in VOICES:
            raise ValueError(f"неизвестный голос: {voice}")
        if not text.strip():
            raise ValueError("пустой текст")
        chunks = [
            np.asarray(result.audio, dtype=np.float32)
            for result in self._load().generate(
                text=text, voice=voice, speed=1.0, lang_code=self._lang_code(voice)
            )
        ]
        if not chunks:
            raise RuntimeError(f"Kokoro ничего не выдал на текст: {text[:60]!r}")
        write_wav_mono16(out_path, np.concatenate(chunks), self.sample_rate)
```

# scripts/voice_bakeoff.py
"""Слепое сравнение голосов.

Гоняет один и тот же абзац через все голоса, пишет версии x1 и x2
под обезличенными именами. Расшифровка лежит в key/mapping.json.

Запуск:
    uv run python scripts/voice_bakeoff.py --out ./bakeoff
"""

import argparse
import json
from pathlib import Path

from book2audio.audio import change_speed
from book2audio.tts.base import TTSEngine
from book2audio.tts.kokoro import KokoroEngine
from book2audio.tts.silero import SileroEngine

RU_TEXT = (
    "Замок на двери был старше самого дома, и открыть его удавалось не с первого раза. "
    "Она стояла на пороге, перебирая связку ключей, и думала о том, что за двадцать лет "
    "здесь не поменялось ровным счётом ничего. «А ты изменился?» — спросила она вслух, "
    "хотя в комнате никого не было. Ответа, разумеется, не последовало."
)

EN_TEXT = (
    "The lock on the door was older than the house itself, and it never opened on the "
    "first try. She stood on the threshold, turning the keyring over in her hands, "
    'thinking that in twenty years nothing here had changed at all. "And have you?" '
    "she asked aloud, though the room was empty. No answer came, of course."
)

TEXT_BY_LANG = {"ru": RU_TEXT, "en": EN_TEXT}


def run_bakeoff(engines: list[tuple[TTSEngine, str]], out_dir: Path) -> dict[str, str]:
    """Синтезирует тестовый абзац всеми голосами. Возвращает расшифровку имён."""
    out_dir.mkdir(parents=True, exist_ok=True)
    (out_dir / "key").mkdir(exist_ok=True)

    mapping: dict[str, str] = {}
    counters: dict[str, int] = {}

    for engine, lang in engines:
        for voice in engine.voices():
            counters[lang] = counters.get(lang, 0) + 1
            label = f"{lang}_{counters[lang]:02d}"
            x1 = out_dir / f"{label}.wav"
            engine.synth(TEXT_BY_LANG[lang], voice, x1)
            change_speed(x1, out_dir / f"{label}_x2.wav", 2.0)
            mapping[label] = f"{engine.name}/{voice}"
            print(f"{label}  готово")

    (out_dir / "key" / "mapping.json").write_text(
        json.dumps(mapping, ensure_ascii=False, indent=2), encoding="utf-8"
    )
    return mapping


def main() -> None:
    parser = argparse.ArgumentParser(description="Слепое сравнение голосов")
    parser.add_argument("--out", type=Path, default=Path("./bakeoff"))
    args = parser.parse_args()

    engines: list[tuple[TTSEngine, str]] = [
        (SileroEngine(model_id="v5_5_ru"), "ru"),
        (SileroEngine(model_id="v5_cis_base"), "ru"),
        (KokoroEngine(), "en"),
    ]
    mapping = run_bakeoff(engines, args.out)
    print(f"\n{len(mapping)} голосов в {args.out}")
    print("Слушай wav, выбирай на слух. Расшифровка в key/mapping.json")


if __name__ == "__main__":
    main()
```

# Фазы 1-5: границы

Детальный TDD-план на каждую фазу пишется отдельно перед её началом через `superpowers:writing-plans`. Здесь только границы и критерий готовности.

### Фаза 1: CLI-скелет. ~10ч

**Что.** PDF в текст, текст в чанки, чанки в Silero, склейка в один wav. Плюс `models.py`, `extract/base.py`, `extract/pdf.py`, `chunker.py`, `tts/cache.py`, `cli.py`.

Извлечение через `page.get_text("dict")`, не голый текст. Словарь даёт координаты, размер шрифта и начертание для каждого спана. Без этих данных фаза 2 невозможна, потерять их нельзя.

Чанкер: `pysbd` режет на предложения, предложения пакуются в чанки до 800 символов, граница предложения не рвётся. Предложение длиннее лимита режется по `;`, потом по `,`.

Паузы: 250 мс между чанками внутри абзаца, 700 мс между абзацами, 1500 мс между главами.

Кэш: `cache/<sha256(text + voice + engine + engine_version)>.wav`. Без него каждое падение стоит всего прогона.

**Готово когда.** `uv run book2audio convert book.pdf --lang ru --voice xenia --out ./output` даёт слушаемый wav на реальной книге.

### Фаза 2: Чистка. ~10ч

**Что.** `clean/pdf_layout.py`, `clean/text.py`, `clean/speech.py`. Самая долгая фаза, сюда уходит треть проекта.

Опорная величина всех эвристик: медианный размер шрифта основного текста, считается один раз по документу.

Только для PDF: порядок блоков и колонки, колонтитулы (форма чаще 30% страниц), номера страниц, маркеры сносок (цифры шрифтом ниже медианного), блоки сносок (ниже медианного плюс нижние 20% страницы), не-проза (моноширинный шрифт, много коротких строк, высокая доля цифр).

Для всех форматов: переносы `(\p{L}+)-\n(\p{Ll}+)` склеиваются в слово, но вторая часть с заглавной означает составное слово и дефис остаётся. Склейка строк: строка без `.!?…»"` на конце приклеивается к следующей. Нормализация под речь: `num2words` для чисел, римские цифры в заголовках, сокращения (`т.е.`, `стр.`, `см.`, `e.g.`, `Fig.`), URL и почта в слово «ссылка».

Ударения не наша забота, Silero v5 ставит сам.

Каждая эвристика получает отдельный тест на фикстуре из реальной страницы. Отчёт пишется в `work/<job_id>/clean_report.json`: сколько блоков выброшено и каким правилом.

**Готово когда.** На трёх разных PDF в отчёте нет ложных срабатываний на основном тексте, и вслух не читаются номера страниц и колонтитулы.

### Фаза 3: EPUB, FB2, m4b. ~10ч

**Что.** `extract/epub.py`, `extract/fb2.py`, `assemble.py`, подключение Kokoro к CLI.

EPUB: читаем spine, каждый документ через BeautifulSoup, `h1`-`h3` в заголовки, `p` в абзацы.

FB2: обход дерева lxml в recover-режиме. `<section>` в главу, `<title>` в заголовок, `<p>` в абзац. Метаданные из `<description>`, обложка из `<binary>`. Выбрасываем `<cite>`, `<epigraph>`, `<table>`, сноски `<a type="note">`.

EPUB и FB2 идут по короткому пути чистки: только `text.py` и `speech.py`. Разметка уже сказала, что заголовок, а что абзац.

Страниц в EPUB и FB2 нет, там главы. Модель `Selection` должна уметь и диапазон страниц, и список глав.

Сборка: конкатенация wav через `concat` demuxer ffmpeg с файлами тишины, метаданные `;FFMETADATA1` с блоками `[CHAPTER]`, кодирование в AAC 64 кбит/с моно, обложка. Опция mp3 по главам с тегами ID3.

**Готово когда.** Все три формата дают m4b с правильными главами. Файл открывается в BookPlayer на iPhone, позиция запоминается, на x2 слушается.

### Фаза 4: Веб-бэкенд. ~8ч

**Что.** `web/main.py`, `web/jobs.py`, `pipeline.py` с событиями прогресса.

Один процесс FastAPI. Синтез в фоне через `ThreadPoolExecutor(max_workers=1)`. Состояние задачи в SQLite в режиме WAL. Отдельный воркер и брокер не нужны: пользователь один, задача одна.

Закрытая вкладка ничего не ломает, состояние живёт на сервере. Перезапуск процесса убивает текущий прогон, но кэш чанков делает повтор дешёвым: заново считается только несинтезированное.

Прогресс через SSE, поток в одну сторону:

```json
{"stage": "synth", "done": 412, "total": 3180, "eta_sec": 2140}
```

ETA по скользящему среднему последних 20 чанков.

Проверки на старте: есть ли `ffmpeg` и `espeak-ng`, хватает ли места на диске (оценка ~2 ГБ промежуточных wav на книгу).

**Готово когда.** Задача ставится через HTTP, переживает закрытие вкладки, прогресс капает в SSE, готовый m4b копируется в папку из конфига.

### Фаза 5: Фронтенд и предпросмотр. ~8ч

**Что.** `web/static/`: одна страница, ванильный JS, ни сборщика, ни фреймворка. Оформление по `elman-practices:elman-design`.

Четыре экрана:

1. **Загрузка.** Drag-and-drop, язык, диапазон страниц или список глав, выбор голоса с кнопкой «прослушать образец»
2. **Предпросмотр.** Текст по главам после чистки, галочки на главах, правка в textarea, счётчик символов, оценка длительности и времени синтеза
3. **Прогресс.** Стадия, полоса, ETA, лог, отмена
4. **Готово.** Плеер, ссылка, путь в iCloud, отчёт по чистке

Экран предпросмотра это главное отличие от черновика. Смысл простой: увидеть мусор до того, как потратил полчаса машинного времени.

Выдача: готовый m4b копируется в папку из конфига, по умолчанию `~/Library/Mobile Documents/com~apple~CloudDocs/Audiobooks`. Файл сам появляется в Файлах на iPhone.

**Готово когда.** Сквозной проход по четырём экранам на реальной книге, README написан, ревью фазы пройдено.
