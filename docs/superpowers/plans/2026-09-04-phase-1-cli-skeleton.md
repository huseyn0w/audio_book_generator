# Фаза 1: CLI-скелет

> **Для агентов:** шаги помечены чекбоксами. TDD обязателен: падающий тест, минимальная реализация, зелёный, коммит.

**Цель.** `book2audio convert book.pdf --lang ru --gender female --out ./output` даёт слушаемый wav из реального PDF.

**Архитектура.** Сквозная цепочка PDF → Document → чанки → Silero → один wav. Чистка в этой фазе минимальная, ей занимается фаза 2. Каждый модуль знает только соседей.

**Тех. стек.** pymupdf, pysbd, typer поверх готовых движков фазы 0.

## Глобальные ограничения

Те же, что в основном плане, плюс:

- Страницы в CLI нумеруются с единицы включительно, внутри PyMuPDF с нуля. Конвертация в одном месте
- Лимит чанка 800 символов, граница предложения не рвётся
- Паузы: 250 мс внутри абзаца, 700 мс между абзацами, 1500 мс между главами
- Кэш обязателен с самого начала. Прогон на полчаса будет падать
- PDF без текстового слоя определяется до синтеза и даёт понятную ошибку

## Тестовый корпус

Реальные книги лежат в ~/Downloads и в репозиторий не идут. Фикстуры это
вырезки в несколько страниц, они коммитятся.

| Фикстура | Источник | Зачем |
|---|---|---|
| `toc_ru.pdf` | 430741.pdf, Кристенсен | Есть закладки и метаданные |
| `no_toc_ru.pdf` | Штраус, «Правда» | Закладок нет, главы по размеру шрифта |
| `scanned_ru.pdf` | Glavnoe_v_istorii_iskusstv.pdf | Нет текстового слоя, ждём ошибку |

Ключевые правила, которые проверяют тесты:

- `Block.kind` только `heading` или `paragraph`, иначе ValueError
- `Block.text` пустым быть не может
- `Selection` не принимает одновременно `pages` и `chapters`
- `Selection.pages` это включительный диапазон с единицы, начало не больше конца, начало не меньше единицы
- `char_count()` суммирует длины текстов блоков

### Задача 1.3: Извлечение PDF

**Файлы:**
- Создать: `book2audio/extract/pdf.py`
- Тест: `tests/extract/test_pdf.py`

**Интерфейсы:**
- Берёт: `Document`, `Chapter`, `Block`, `Selection`, `NoTextLayer`
- Отдаёт: `PdfExtractor()` с `extract(path, selection) -> Document`, функции `median_font_size(spans)`, `blocks_from_page(page)`

**Что важно.** Берём `page.get_text("dict")`, а не голый текст. Словарь даёт размер шрифта, начертание и bbox каждого спана. Фаза 2 без этих данных не сделается, терять их нельзя.

Главы: сначала пробуем `doc.get_toc()`. Если закладок нет, заголовком считаем блок, у которого размер шрифта заметно выше медианного по документу.

Диапазон страниц применяется при чтении: страницы вне диапазона не открываются.

Текстовый слой: если среднее число символов на страницу ниже порога, кидаем `NoTextLayer` с понятным текстом про OCR.

### Задача 1.4: Чанкер

**Файлы:**
- Создать: `book2audio/chunker.py`
- Тест: `tests/test_chunker.py`

**Интерфейсы:**
- Отдаёт: `Chunk(text, pause_after)`, `chunk_document(doc, language, limit=800) -> list[Chunk]`, `PAUSE_IN_PARAGRAPH`, `PAUSE_BETWEEN_PARAGRAPHS`, `PAUSE_BETWEEN_CHAPTERS`

**Что важно.** `pysbd` режет на предложения и умеет ru и en. Предложения пакуются в чанк до лимита, граница предложения не рвётся. Предложение длиннее лимита режем по `;`, потом по `,`, в последнюю очередь по словам: лучше некрасивая пауза, чем упавший синтез.

## Критерий готовности фазы

```bash
uv run pytest                       # всё зелёное
uv run ruff check . && uv run ruff format --check .
uv run book2audio convert ~/Downloads/430741.pdf --lang ru --gender female \
    --pages 22-40 --out ./output
```

На выходе wav, который слушается, главы читаются в правильном порядке,
номера страниц вслух не произносятся сильнее, чем позволяет отсутствие
фазы 2.
