# Фаза 3: EPUB, FB2 и сборка m4b

**Цель.** Все три формата дают m4b с главами, который открывается на iPhone
и запоминает позицию.

**Основание.** Разбор реальных файлов, а не спецификаций. Книга Кристенсена
лежит в ~/Downloads во всех трёх форматах, это готовый корпус для сверки.

## Что показал разбор

| | PDF | EPUB | FB2 |
|---|---|---|---|
| Единиц структуры | 549 страниц | 240 файлов spine | 14 секций верхнего уровня |
| Заголовки в разметке | нет | **нет h1-h3** | `<title>` в каждой секции |
| Оглавление | закладки | вложенное дерево с якорями | вложенность секций |
| Сноски | по шрифту | в тексте | **отдельный body name="notes"** |

Два вывода, меняющих черновик.

**В EPUB нет h1-h3.** Черновик предлагал брать главы из них. На реальном
файле их ноль, а spine разбит на 240 кусков по несколько абзацев. Главы
берутся из оглавления, как закладки в PDF: `href` вида `ch1-4.xhtml#id3`,
поэтому резать надо по якорю внутри файла, а не по файлу.

**В FB2 сноски лежат в отдельном body.** У Кристенсена это 202 секции.
Читать их вслух нельзя, и по шрифту их не отличить: шрифта в FB2 нет.
Берём только первый body без атрибута name.

## Задачи

### 3.1: Фикстуры EPUB и FB2
`scripts/make_fixtures.py` учится резать EPUB и FB2. Тесты проверяют, что
в фикстурах есть то, ради чего они взяты: вложенное оглавление с якорями
у EPUB, body с примечаниями у FB2.

### 3.2: Извлечение FB2
`book2audio/extract/fb2.py` на lxml в recover-режиме.
Первый body, рекурсивный обход секций, `<title>` в заголовок, `<p>` в абзац.
Выбрасываем `<cite>`, `<epigraph>`, `<table>`, `<a type="note">`.
Метаданные из `<description>`, язык из `<lang>`.
Тяжёлые эвристики не нужны: разметка уже сказала, что есть что.
Прогоняем только `clean_text` и `normalize_for_speech`.

### 3.3: Извлечение EPUB
`book2audio/extract/epub.py` на ebooklib и BeautifulSoup с парсером xml.
Порядок из `book.spine`, а не из порядка элементов.
Оглавление разворачивается в плоский список (заголовок, файл, якорь).
Блоки режутся по якорям.

### 3.4: Выбор глав вместо страниц
`Selection.chapters` начинает работать: у EPUB и FB2 страниц нет.
CLI получает `--chapters 1-3` и команду `chapters`, показывающую список.

### 3.5: Сборка m4b
`book2audio/assemble.py`: AAC 64 кбит/с моно, блоки `[CHAPTER]` в
`;FFMETADATA1`, обложка, метаданные названия и автора.
Опция `--format mp3` даёт папку с пронумерованными файлами и тегами.

### 3.6: Английский и выдача
Kokoro подключается к CLI как рабочий движок, а не только через `voices`.
Готовый файл копируется в папку из конфига, по умолчанию
`~/Library/Mobile Documents/com~apple~CloudDocs/Audiobooks`.

## Критерий готовности

```bash
uv run book2audio convert ~/Downloads/430741.fb2  --lang ru --chapters 4-5 --out ./output
uv run book2audio convert ~/Downloads/430741.epub --lang ru --chapters 4-5 --out ./output
uv run book2audio convert ~/Downloads/430741.pdf  --lang ru --pages 22-40  --out ./output
```

Три формата одной книги дают сопоставимый текст. m4b открывается на iPhone,
главы на месте, позиция запоминается.
